# GPA Calculator

A simple, accessible web application for calculating grade-point averages from course grades and credit hours.

## Features

- Enter courses, grades, and credit hours
- Calculate a weighted GPA
- Clear, browser-based interface
- No server or database required

## Technology

- HTML5
- CSS3
- JavaScript

## Getting Started

```bash
git clone https://github.com/sameer-softengs/Gpa-calculator.git
cd Gpa-calculator
```

Open `index.html` in a modern browser to use the calculator.

## Usage

1. Enter the course information.
2. Provide the corresponding credit hours and grade.
3. Review the calculated GPA.
